[Source](https://docs.rs/bevy_ecs/0.19.0/x86_64-unknown-linux-gnu/src/bevy_ecs/system/exclusive_function_system.rs.html#207)

```rust
pub trait ExclusiveSystemParamFunction<Marker>:
    Send
    + Sync
    + 'static {
    type In: SystemInput;
    type Out;
    type Param: ExclusiveSystemParam;

    // Required method
    fn run(
        &mut self,

```

A trait implemented for all exclusive system functions that can be used as [`System`](../../prelude/trait.System.html "trait bevy::prelude::System")s.

This trait can be useful for making your own systems which accept other systems, sometimes called higher order systems.
