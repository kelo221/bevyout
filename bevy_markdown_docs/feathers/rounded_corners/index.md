# Module rounded\_corners 

[Source](https://docs.rs/bevy_feathers/0.19.0/x86_64-unknown-linux-gnu/src/bevy_feathers/lib.rs.html#58)

Mechanism for specifying which corners of a widget are rounded, used for segmented buttons and control groups.

## Enums

[RoundedCorners](enum.RoundedCorners.html "enum bevy::feathers::rounded_corners::RoundedCorners")

Allows specifying which corners are rounded and which are sharp. All rounded corners have the same radius. Not all combinations are supported, only the ones that make sense for a segmented buttons.
