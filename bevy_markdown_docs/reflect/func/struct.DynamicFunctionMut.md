# Struct DynamicFunctionMut

Available on **crate feature `functions`** only.

A dynamic representation of a function.

This type can be used to represent any callable that satisfies [`FnMut`](https://doc.rust-lang.org/nightly/core/ops/function/trait.FnMut.html "trait core::ops::function::FnMut") (or the reflection-based equivalent, [`ReflectFnMut`](trait.ReflectFnMut.html "trait bevy::reflect::func::ReflectFnMut")). That is, any function or closure.

For functions that do not need to capture their environment mutably, it’s recommended to use [`DynamicFunction`](struct.DynamicFunction.html "struct bevy::reflect::func::DynamicFunction") instead.

This type can be seen as a superset of [`DynamicFunction`](struct.DynamicFunction.html "struct bevy::reflect::func::DynamicFunction").

See the [module-level documentation](index.html "mod bevy::reflect::func") for more information.

You will generally not need to construct this manually. Instead, many functions and closures can be automatically converted using the [`IntoFunctionMut`](../../prelude/trait.IntoFunctionMut.html "trait bevy::prelude::IntoFunctionMut") trait.

## Example

Most of the time, a [`DynamicFunctionMut`](struct.DynamicFunctionMut.html "struct bevy::reflect::func::DynamicFunctionMut") can be created using the [`IntoFunctionMut`](../../prelude/trait.IntoFunctionMut.html "trait bevy::prelude::IntoFunctionMut") trait:

```rust
let mut list: Vec<i32> = vec![1, 2, 3];

// `replace` is a closure that captures a mutable reference to `list`
let mut replace = |index: usize, value: i32| -> i32 {
  let old_value = list[index];
  list[index] = value;
  old_value
};

// Since this closure mutably borrows data, we can't convert it into a regular `DynamicFunction`,
// as doing so would result in a compile-time error:
// let mut func: DynamicFunction = replace.into_function();

// Instead, we convert it into a `DynamicFunctionMut` using `IntoFunctionMut::into_function_mut`:
let mut func: DynamicFunctionMut = replace.into_function_mut();

// Dynamically call it:
let args = ArgList::default().with_owned(1_usize).with_owned(-2_i32);
let value = func.call(args).unwrap().unwrap_owned();

// Check the result:
assert_eq!(value.try_take::<i32>().unwrap(), 2);

// Note that `func` still has a reference to `list`,
// so we need to drop it before we can access `list` again.
// Alternatively, we could have invoked `func` with
// `DynamicFunctionMut::call_once` to immediately consume it.
drop(func);
assert_eq!(list, vec![1, -2, 3]);
```

#### pub fn [with\_overload](#method.with_overload)<'a, F, Marker>(self, function: F) -> [DynamicFunctionMut](struct.DynamicFunctionMut.html "struct bevy::reflect::func::DynamicFunctionMut")<'a>

where 'env: 'a, F: [IntoFunctionMut](../../prelude/trait.IntoFunctionMut.html "trait bevy::prelude::IntoFunctionMut")<'a, Marker>,

Add an overload to this function.

Overloads allow a single [`DynamicFunctionMut`](struct.DynamicFunctionMut.html "struct bevy::reflect::func::DynamicFunctionMut") to represent multiple functions of different signatures.

This can be used to handle multiple monomorphizations of a generic function or to allow functions with a variable number of arguments.

Any functions with the same [argument signature](signature/struct.ArgumentSignature.html "struct bevy::reflect::func::signature::ArgumentSignature") will be overwritten by the one from the new function, `F`. For example, if the existing function had the signature `(i32, i32) -> i32`, and the new function, `F`, also had the signature `(i32, i32) -> i32`, the one from `F` would replace the one from the existing function.

Overloaded functions retain the [name](struct.DynamicFunctionMut.html#method.name "method bevy::reflect::func::DynamicFunctionMut::name") of the original function.

Note that it may be impossible to overload closures that mutably borrow from their environment due to Rust’s borrowing rules. However, it’s still possible to overload functions that do not capture their environment mutably, or those that maintain mutually exclusive mutable references to their environment.

##### Panics

Panics if the function, `F`, contains a signature already found in this function.

For a non-panicking version, see [`try_with_overload`](struct.DynamicFunctionMut.html#method.try_with_overload "method bevy::reflect::func::DynamicFunctionMut::try_with_overload").

##### Example

```rust
let mut total_i32 = 0;
let mut add_i32 = |a: i32| total_i32 += a;

let mut total_f32 = 0.0;
let mut add_f32 = |a: f32| total_f32 += a;

// Currently, the only generic type `func` supports is `i32`.
let mut func = add_i32.into_function_mut();

// However, we can add an overload to handle `f32` as well:
func = func.with_overload(add_f32);

// Test `i32`:
let args = bevy_reflect::func::ArgList::new().with_owned(123_i32);
func.call(args).unwrap();

// Test `f32`:
let args = bevy_reflect::func::ArgList::new().with_owned(1.23_f32);
func.call(args).unwrap();

drop(func);
assert_eq!(total_i32, 123);
assert_eq!(total_f32, 1.23);
```

#### pub fn [call](#method.call)<'a>( &mut self, args: [ArgList](struct.ArgList.html "struct bevy::reflect::func::ArgList")<'a>, ) -> [Result](https://doc.rust-lang.org/nightly/core/result/enum.Result.html "enum core::result::Result")<[Return](enum.Return.html "enum bevy::reflect::func::Return")<'a>, [FunctionError](enum.FunctionError.html "enum bevy::reflect::func::FunctionError")\>

Call the function with the given arguments.

Variables that are captured mutably by this function won’t be usable until this function is dropped. Consider using [`call_once`](struct.DynamicFunctionMut.html#method.call_once "method bevy::reflect::func::DynamicFunctionMut::call_once") if you want to consume the function immediately after calling it.

##### Example

```rust
let mut total = 0;
let add = |a: i32, b: i32| -> i32 {
  total = a + b;
  total
};

let mut func = add.into_function_mut().with_name("add");
let args = ArgList::new().with_owned(25_i32).with_owned(75_i32);
let result = func.call(args).unwrap().unwrap_owned();
assert_eq!(result.try_take::<i32>().unwrap(), 100);
```

##### Errors

This method will return an error if the number of arguments provided does not match the number of arguments expected by the function’s [`FunctionInfo`](struct.FunctionInfo.html "struct bevy::reflect::func::FunctionInfo").

The function itself may also return any errors it needs to.

#### pub fn [call\_once](#method.call_once)(self, args: [ArgList](struct.ArgList.html "struct bevy::reflect::func::ArgList")<'\_>) -> [Result](https://doc.rust-lang.org/nightly/core/result/enum.Result.html "enum core::result::Result")<[Return](enum.Return.html "enum bevy::reflect::func::Return")<'\_>, [FunctionError](enum.FunctionError.html "enum bevy::reflect::func::FunctionError")\>

This is useful for functions that capture their environment mutably because otherwise any captured variables would still be borrowed by it.

##### Example

```rust

let increment_function = increment.into_function_mut();
```

#### pub fn [arg\_count](#method.arg_count)(&self) -> [ArgCount](args/struct.ArgCount.html "struct bevy::reflect::func::args::ArgCount")

Returns the number of arguments the function expects.

For [overloaded](struct.DynamicFunctionMut.html#method.with_overload "method bevy::reflect::func::DynamicFunctionMut::with_overload") functions that can have a variable number of arguments, this will contain the full set of counts for all signatures.

##### Example

```rust
let add = (|a: i32, b: i32| a + b).into_function_mut();

assert!(add.arg_count().contains(2));
assert!(add.arg_count().contains(3));
```
