Defines which rendering layers an entity belongs to.

A camera renders an entity only when their render layers intersect.

The [`Default`](https://doc.rust-lang.org/nightly/core/default/trait.Default.html "trait core::default::Default") instance of `RenderLayers` contains layer `0`, the first layer. Entities without this component also belong to layer `0`.

An empty `RenderLayers` makes the entity invisible.
