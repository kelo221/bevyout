[Source](https://docs.rs/bevy_app/0.19.0/x86_64-unknown-linux-gnu/src/bevy_app/plugin_group.rs.html#232)

pub struct PluginGroupBuilder { /* private fields */ }

Facilitates the creation and configuration of a [`PluginGroup`](../prelude/trait.PluginGroup.html "trait bevy::prelude::PluginGroup").

Provides a build ordering to ensure that [`Plugin`](../prelude/trait.Plugin.html "trait bevy::prelude::Plugin")s which produce/require a [`Resource`](../prelude/trait.Resource.html "trait bevy::prelude::Resource") are built before/after dependent/depending [`Plugin`](../prelude/trait.Plugin.html "trait bevy::prelude::Plugin")s. [`Plugin`](../prelude/trait.Plugin.html "trait bevy::prelude::Plugin")s inside the group can be disabled, enabled or reordered.

Enables a [`Plugin`](../prelude/trait.Plugin.html "trait bevy::prelude::Plugin").

[`Plugin`](../prelude/trait.Plugin.html "trait bevy::prelude::Plugin")s within a [`PluginGroup`](../prelude/trait.PluginGroup.html "trait bevy::prelude::PluginGroup") are enabled by default. This function is used to opt back in to a [`Plugin`](../prelude/trait.Plugin.html "trait bevy::prelude::Plugin") after [disabling](struct.PluginGroupBuilder.html#method.disable "method bevy::app::PluginGroupBuilder::disable") it. where T: [Plugin](../prelude/trait.Plugin.html "trait bevy::prelude::Plugin"),

Disables a [`Plugin`](../prelude/trait.Plugin.html "trait bevy::prelude::Plugin"), preventing it from being added to the [`App`](../prelude/struct.App.html "struct bevy::prelude::App") with the rest of the [`PluginGroup`](../prelude/trait.PluginGroup.html "trait bevy::prelude::PluginGroup"). If there are no plugins of type `T` in this group, it will panic.
