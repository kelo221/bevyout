The defining [`Component`](trait.Component.html "trait bevy::prelude::Component") for camera entities, storing information about how and what to render through this camera.

The [`Camera`](struct.Camera.html "struct bevy::prelude::Camera") component is added to an entity to define the properties of the viewpoint from which rendering occurs. It defines the position of the view to render, the projection method to transform the 3D objects into a 2D image, as well as the render target into which that image is produced.

Note that a [`Camera`](struct.Camera.html "struct bevy::prelude::Camera") needs a `CameraRenderGraph` to render anything. This is typically provided by adding a [`Camera2d`](struct.Camera2d.html "struct bevy::prelude::Camera2d") or [`Camera3d`](struct.Camera3d.html "struct bevy::prelude::Camera3d") component, but custom render graphs can also be defined. Inserting a [`Camera`](struct.Camera.html "struct bevy::prelude::Camera") with no render graph will emit an error at runtime.

`order: [isize](https://doc.rust-lang.org/nightly/std/primitive.isize.html)`

`is_active: [bool](https://doc.rust-lang.org/nightly/std/primitive.bool.html)`

If this is set to `true`, this camera will be rendered to its specified [`RenderTarget`](../camera/enum.RenderTarget.html "enum bevy::camera::RenderTarget"). If `false`, this camera will not be rendered.

`computed: [ComputedCameraValues](../camera/struct.ComputedCameraValues.html "struct bevy::camera::ComputedCameraValues")`

Computed values for this camera, such as the projection matrix and the render target size.

`output_mode: [CameraOutputMode](../camera/enum.CameraOutputMode.html "enum bevy::camera::CameraOutputMode")`

The [`CameraOutputMode`](../camera/enum.CameraOutputMode.html "enum bevy::camera::CameraOutputMode") for this camera.

`msaa_writeback: [MsaaWriteback](enum.MsaaWriteback.html "enum bevy::prelude::MsaaWriteback")`

Controls when MSAA writeback occurs for this camera. See [`MsaaWriteback`](enum.MsaaWriteback.html "enum bevy::prelude::MsaaWriteback") for available options.

`clear_color: [ClearColorConfig](enum.ClearColorConfig.html "enum bevy::prelude::ClearColorConfig")`

The clear color operation to perform on the render target.

`invert_culling: [bool](https://doc.rust-lang.org/nightly/std/primitive.bool.html)`

Whether to switch culling mode so that materials that request backface culling cull front faces, and vice versa.

This is typically used for cameras that mirror the world that they render across a plane, because doing that flips the winding of each polygon.

This setting doesn’t affect materials that disable backface culling.

`sub_camera_view: [Option](https://doc.rust-lang.org/nightly/core/option/enum.Option.html "enum core::option::Option")<[SubCameraView](../camera/struct.SubCameraView.html "struct bevy::camera::SubCameraView")>`
