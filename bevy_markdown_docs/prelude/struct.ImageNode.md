A UI Node that renders an image.

## Fields

`color: [Color](enum.Color.html "enum bevy::prelude::Color")`

The tint color used to draw the image.

This is multiplied by the color of each pixel in the image. The field value defaults to solid white, which will pass the image through unmodified.

`image: [Handle](enum.Handle.html "enum bevy::prelude::Handle")<[Image](struct.Image.html "struct bevy::prelude::Image")>`

Handle to the texture.

This defaults to a [`TRANSPARENT_IMAGE_HANDLE`](../image/constant.TRANSPARENT_IMAGE_HANDLE.html "constant bevy::image::TRANSPARENT_IMAGE_HANDLE"), which points to a fully transparent 1x1 texture.

`texture_atlas: [Option](https://doc.rust-lang.org/nightly/core/option/enum.Option.html "enum core::option::Option")<[TextureAtlas](struct.TextureAtlas.html "struct bevy::prelude::TextureAtlas")>`

The (optional) texture atlas used to render the image.

`flip_x: [bool](https://doc.rust-lang.org/nightly/std/primitive.bool.html)`

Whether the image should be flipped along its x-axis.

`flip_y: [bool](https://doc.rust-lang.org/nightly/std/primitive.bool.html)`

Whether the image should be flipped along its y-axis.

`rect: [Option](https://doc.rust-lang.org/nightly/core/option/enum.Option.html "enum core::option::Option")<[Rect](struct.Rect.html "struct bevy::prelude::Rect")>`

An optional rectangle representing the region of the image to render, instead of rendering the full image. This is an easy one-off alternative to using a [`TextureAtlas`](struct.TextureAtlas.html "struct bevy::prelude::TextureAtlas").

When used with a [`TextureAtlas`](struct.TextureAtlas.html "struct bevy::prelude::TextureAtlas"), the rect is offset by the atlas’s minimal (top-left) corner position.

`image_mode: [NodeImageMode](enum.NodeImageMode.html "enum bevy::prelude::NodeImageMode")`

Controls how the image is altered to fit within the layout and how the layout algorithm determines the space to allocate for the image.

`visual_box: [VisualBox](enum.VisualBox.html "enum bevy::prelude::VisualBox")`

Which region of the UI node the image should be drawn within.
