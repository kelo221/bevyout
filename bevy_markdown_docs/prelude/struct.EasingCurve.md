A [`Curve`](trait.Curve.html "trait bevy::prelude::Curve") that is defined by

*   an initial `start` sample value at `t = 0`
*   a final `end` sample value at `t = 1`
*   an [easing function](enum.EaseFunction.html "enum bevy::prelude::EaseFunction") to interpolate between the two values.

The resulting curve’s domain is always [the unit interval](struct.Interval.html#associatedconstant.UNIT "associated constant bevy::prelude::Interval::UNIT").

## Example

Create a linear curve that interpolates between `2.0` and `4.0`.

```rust
let c = EasingCurve::new(2.0, 4.0, EaseFunction::Linear);
```

[`sample`](struct.EasingCurve.html#method.sample "method bevy::prelude::EasingCurve::sample") the curve at various points. This will return `None` if the parameter is outside the unit interval.

```rust
assert_eq!(c.sample(-1.0), None);
assert_eq!(c.sample(0.0), Some(2.0));
assert_eq!(c.sample(0.5), Some(3.0));
assert_eq!(c.sample(1.0), Some(4.0));
assert_eq!(c.sample(2.0), None);
```

[`sample_clamped`](struct.EasingCurve.html#method.sample_clamped "method bevy::prelude::EasingCurve::sample_clamped") will clamp the parameter to the unit interval, so it always returns a value.

```rust
assert_eq!(c.sample_clamped(-1.0), 2.0);
assert_eq!(c.sample_clamped(0.0), 2.0);
assert_eq!(c.sample_clamped(0.5), 3.0);
assert_eq!(c.sample_clamped(1.0), 4.0);
assert_eq!(c.sample_clamped(2.0), 4.0);
```

`EasingCurve` can be used with any type that implements the [`Ease`](trait.Ease.html "trait bevy::prelude::Ease") trait. This includes many math types, like vectors and rotations.

```rust
let c = EasingCurve::new(
    Vec2::new(0.0, 4.0),
    Vec2::new(2.0, 8.0),
    EaseFunction::Linear,
);

assert_eq!(c.sample_clamped(0.5), Vec2::new(1.0, 6.0));
```

```rust
let c = EasingCurve::new(
    Rot2::degrees(10.0),
    Rot2::degrees(20.0),
    EaseFunction::Linear,
);

assert_abs_diff_eq!(c.sample_clamped(0.5), Rot2::degrees(15.0));
```

As a shortcut, an `EasingCurve` between `0.0` and `1.0` can be replaced by [`EaseFunction`](enum.EaseFunction.html "enum bevy::prelude::EaseFunction").

```rust
let f = EaseFunction::SineIn;
let c = EasingCurve::new(0.0, 1.0, EaseFunction::SineIn);

assert_eq!(f.sample(t), c.sample(t));
```
