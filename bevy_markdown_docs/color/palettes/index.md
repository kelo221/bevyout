# Module palettes 

[Source](https://docs.rs/bevy_color/0.19.0/x86_64-unknown-linux-gnu/src/bevy_color/lib.rs.html#114)

Color palettes consisting of collections of const colors.

## Modules

[basic](basic/index.html "mod bevy::color::palettes::basic")

Named colors from the CSS1 specification, also known as [basic colors](https://en.wikipedia.org/wiki/Web_colors#Basic_colors). This is the same set of colors used in the [VGA graphics standard](https://en.wikipedia.org/wiki/Video_Graphics_Array).

[css](css/index.html "mod bevy::color::palettes::css")

[Extended colors from the CSS4 specification](https://en.wikipedia.org/wiki/Web_colors#Extended_colors), Also known as X11 colors, which were standardized in HTML 4.0.

[tailwind](tailwind/index.html "mod bevy::color::palettes::tailwind")

Colors from [Tailwind CSS](https://tailwindcss.com/docs/customizing-colors) (MIT License). Grouped by hue with numeric lightness scale (50 is light, 950 is dark).
