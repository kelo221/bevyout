# Struct AccumulatedMouseScroll 

[Source](https://docs.rs/bevy_input/0.19.0/x86_64-unknown-linux-gnu/src/bevy_input/mouse.rs.html#239)

```rust
pub struct AccumulatedMouseScroll {
    pub unit: MouseScrollUnit,
    pub delta: Vec2,
}
```

Available on **crate feature `mouse`** only.

Tracks how much the mouse has scrolled every frame.

This resource is reset to zero every frame.

This resource sums the total [`MouseWheel`](struct.MouseWheel.html "struct bevy::input::mouse::MouseWheel") events received this frame.

## Fields

`unit: [MouseScrollUnit](enum.MouseScrollUnit.html "enum bevy::input::mouse::MouseScrollUnit")`

The mouse scroll unit. If this value changes while scrolling, then the result of the accumulation could be incorrect

`delta: [Vec2](../../prelude/struct.Vec2.html "struct bevy::prelude::Vec2")`

The change in scroll position.
